Blog posts support [Docusaurus Markdown features](https://docusaurus.io/docs/markdown-features), such as [MDX](https://mdxjs.com/).

## Interactive Components

You can use JSX to create interactive components in your documentation. For example, here's an interactive theme preview:

```jsx
<button onClick={() => alert('Theme preview clicked!')}>Preview Theme</button>
```

## Benefits of MDX

- **Interactive examples**: Embed working components in documentation
- **Dynamic content**: Create responsive documentation
- **Better engagement**: Keep readers engaged with interactive elements
- **Code examples**: Show live code examples with working demos

## Use Cases for EDS Multi-Brand

- Theme configuration wizards
- Component preview tools
- Brand switching demos
- Interactive tutorials

This makes our documentation more engaging and helps developers understand concepts faster!
