We're excited to announce the launch of the EDS Multi-Brand project! This project provides a comprehensive solution for managing multiple brands within Adobe Experience Manager.

<!-- truncate -->

The EDS Multi-Brand project enables developers to create and manage multiple brand experiences from a single codebase. With shared components and brand-specific theming, you can maintain consistency while allowing for brand differentiation.

Key features include:

- **Multi-brand theming system**
- **Shared component library**
- **Brand-specific customizations**
- **Automated deployment workflows**

Stay tuned for more updates and detailed documentation on how to get started with the EDS Multi-Brand project!
